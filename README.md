# 焼肉山王苑 公式サイト

東京・大森の焼肉店「焼肉山王苑」の公式サイト。素の HTML / CSS / JS のみで構成した1ページ。

## 構成

```
build/
  index.html
  assets/css/style.css
  assets/js/main.js
  assets/img/          （実写真の置き場。現在は未配置）
```

外部依存は Google Fonts（Shippori Mincho B1 / Noto Sans JP / Montserrat）のみ。
相対パス構成なので `build/index.html` をそのまま開いても動作する。

## 未対応の項目

- **創業年**。1980年は報道で裏取り済み（東京ウォーカー 2015年8月23日「33年愛された前山王苑を2013年5月に譲り受けてリニューアルオープン」からの逆算）。ただし厳密な創業年月の一次資料は未発見のため「頃」の精度である点に留意
- **写真3点**。現在は系列店（わびのや）の写真を仮置きしている。差し替え位置は `index.html` 内の HTML コメントに記載
  1. 名物ハラミの一皿（8:3）── 仮: 系列店のハラミ
  2. 1F カウンターと卓上七輪（8:3）── 仮: 系列店の店内
  3. 店舗外観・夕景（縦位置）── 仮: 系列店の料理写真。**最重要の差し替え対象**
