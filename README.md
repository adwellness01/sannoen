# 焼肉山王苑 公式サイト

東京・大森の焼肉店「焼肉山王苑」の公式サイト。素の HTML / CSS / JS のみで構成した1ページ。

## 構成

```
build/
  index.html
  assets/css/style.css
  assets/js/main.js
  assets/img/          （2026-09-17 撮影の実写真8点）
```

外部依存は Google Fonts（Shippori Mincho B1 / Noto Sans JP / Montserrat）のみ。
相対パス構成なので `build/index.html` をそのまま開いても動作する。
