# 理解テスト（社内用）

`index.html`（固定の入口）が `page.html` / `furigana.js` / `app.js` を毎回サーバーから読み込んで動く画面。

- **問題・正解・採点・受験者の管理はこのリポジトリに無い。** Google Apps Script のウェブアプリ（スプレッドシート「山王苑 理解テスト管理」に紐づくプロジェクト）が持っていて、`app.js` の `API_URL` から呼ぶ。問題の追加・修正はそちらの `問題.gs` で行う。
- 受験者は ID と PIN で入る。受験日時（受験枠）の外ではサーバーが問題を返さない。採点はサーバー側で、8割以上で次の段階へ進む。
- ふりがなは `furigana.js` の辞書（漢字語 → 読み）。問題を追加したら管理モード（ID: admin）→「ふりがな未登録の漢字を確認」で不足を確認して辞書に足す。
- 画面の文言・見た目は `page.html`、動作は `app.js`。
- localhost で開いたときだけ `_mock/` のモックAPI（リポジトリ外の GAS ソースをローカルサーバーが配信）を読み込んで動作確認できる。
